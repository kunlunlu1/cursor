## 算法手册（题目 + 思路 + 对应算法）

> 目标：按高频题型补全“题目—解题思路—核心算法”，便于面试前快速复习。

### 1) 数组与双指针

1. 两数之和（Two Sum）  
   - 思路：遍历数组，检查 `target - nums[i]` 是否已出现。  
   - 算法：哈希表（一次遍历）。
2. 三数之和（3Sum）  
   - 思路：排序后固定一个数，剩余区间做左右夹逼。  
   - 算法：排序 + 双指针。
3. 盛最多水的容器（Container With Most Water）  
   - 思路：左右指针向中间收缩，每次移动短板。  
   - 算法：贪心 + 双指针。
4. 移动零（Move Zeroes）  
   - 思路：快慢指针把非零元素前移，后面补零。  
   - 算法：双指针原地覆盖。

### 2) 滑动窗口

1. 无重复字符的最长子串  
   - 思路：右扩窗口，若重复则左指针收缩直到合法。  
   - 算法：滑动窗口 + 哈希计数/最近位置。
2. 最小覆盖子串  
   - 思路：先扩张满足覆盖，再收缩求最短。  
   - 算法：滑动窗口 + 频次数组/哈希表。
3. 找到字符串中所有字母异位词  
   - 思路：固定窗口长度，维护窗口字符频次。  
   - 算法：定长滑动窗口 + 计数数组。

### 3) 二分查找

1. 搜索旋转排序数组  
   - 思路：每次判断哪一半有序，再判断目标是否在有序半区。  
   - 算法：变形二分。
2. 寻找峰值  
   - 思路：比较 `mid` 与 `mid+1`，向上坡方向二分。  
   - 算法：二分答案/趋势二分。
3. 在排序数组中查找元素第一个和最后一个位置  
   - 思路：分别写“左边界二分”和“右边界二分”。  
   - 算法：边界二分模板。

### 4) 链表

1. 反转链表  
   - 思路：逐个节点改变 `next` 指向。  
   - 算法：迭代指针操作（或递归）。
2. 环形链表 II  
   - 思路：快慢指针首次相遇后，头节点与相遇点同步前进再相遇。  
   - 算法：Floyd 判圈。
3. 合并 K 个升序链表  
   - 思路：每次取当前最小节点接到结果后。  
   - 算法：最小堆（优先队列）或分治归并。

### 5) 二叉树与递归

1. 二叉树层序遍历  
   - 思路：按层出队，记录每层节点。  
   - 算法：BFS（队列）。
2. 二叉树最近公共祖先  
   - 思路：后序递归，左右子树返回值决定当前节点是否为 LCA。  
   - 算法：DFS + 分治。
3. 验证二叉搜索树  
   - 思路：中序遍历应严格递增；或递归维护上下界。  
   - 算法：中序遍历 / 递归边界。

### 6) 回溯

1. 全排列  
   - 思路：路径 + 可选列表，选一个、递归、撤销选择。  
   - 算法：回溯模板。
2. 子集  
   - 思路：每个元素都有“选/不选”两种决策。  
   - 算法：回溯/位运算枚举。
3. 组合总和  
   - 思路：按起点递归，剪枝（剩余和 < 0 时返回）。  
   - 算法：回溯 + 剪枝。

### 7) 动态规划

1. 爬楼梯  
   - 思路：到第 i 阶的方法数等于前两阶之和。  
   - 算法：一维 DP（斐波那契型）。
2. 最长递增子序列（LIS）  
   - 思路：`dp[i]` 表示以 `i` 结尾 LIS；进阶用牌堆法。  
   - 算法：DP O(n²) / 贪心+二分 O(nlogn)。
3. 0/1 背包  
   - 思路：状态为容量，倒序遍历保证每件物品只用一次。  
   - 算法：二维/一维背包 DP。
4. 编辑距离  
   - 思路：字符相同继承左上，不同取插删改最小 +1。  
   - 算法：二维 DP。

### 8) 图论

1. 岛屿数量  
   - 思路：遍历网格，遇到陆地就 DFS/BFS 淹没连通块。  
   - 算法：网格图遍历。
2. 课程表  
   - 思路：判断有向图是否有环。  
   - 算法：拓扑排序（Kahn）/ DFS 染色。
3. 最短路径（非负权）  
   - 思路：每次选择当前最短未确定点并松弛邻边。  
   - 算法：Dijkstra（堆优化）。

### 9) 单调栈 / 堆

1. 每日温度  
   - 思路：维护递减栈，当前温度更高则弹栈结算答案。  
   - 算法：单调栈。
2. 柱状图中最大的矩形  
   - 思路：找每根柱子左右第一个更小元素作为边界。  
   - 算法：单调栈 + 哨兵。
3. 前 K 个高频元素  
   - 思路：先统计频次，再保留 Top-K。  
   - 算法：哈希 + 小顶堆（或桶排序）。

## 常用“简单但麻烦”的关键操作（含矩阵）

### 1) 矩阵遍历方向模板

- 四连通方向：`[(1,0),(-1,0),(0,1),(0,-1)]`
- 八连通方向：在四连通基础上增加四个对角。

### 2) 矩阵边界判断

- 判断坐标 `(x, y)` 是否有效：  
  `0 <= x < rows && 0 <= y < cols`

### 3) 矩阵旋转（顺时针 90°）

思路：先转置，再每行反转。  
适用：`n x n` 方阵原地旋转。

### 4) 矩阵螺旋遍历

思路：维护上、下、左、右四条边界，分四段走完一圈后收缩边界。  
注意：每段遍历前检查边界是否仍有效，避免重复访问。

### 5) 前缀和（数组 / 二维矩阵）

1. 一维前缀和  
   - `pre[i] = pre[i-1] + nums[i]`  
   - 区间和：`sum(l..r) = pre[r] - pre[l-1]`
2. 二维前缀和  
   - `pre[i][j]` 表示左上角到 `(i,j)` 子矩阵和。  
   - 子矩阵和用容斥：`A - B - C + D`。

### 6) 差分（区间批量更新）

1. 一维差分  
   - 区间 `[l,r]` 加 `k`：`diff[l]+=k, diff[r+1]-=k`
2. 二维差分  
   - 子矩阵批量加值后，最后一次前缀还原得到结果矩阵。

### 7) 快速幂

思路：指数按二进制拆分，底数不断平方。  
算法：二分幂，复杂度 `O(log n)`。

### 8) 位运算常见技巧

- 判断奇偶：`x & 1`
- 取最低位 1：`x & -x`
- 清除最低位 1：`x & (x - 1)`
- 子集枚举（位掩码）：`for mask in [0, 2^n)`

### 9) 字符串处理细节

- 回文判断：双指针从两端向中间。  
- KMP：适合模式串重复结构明显的多次匹配。  
- 字符频次统计：优先数组（定字符集）或哈希（通用字符集）。
